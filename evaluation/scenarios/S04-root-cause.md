# S04 — Recurring failure / Five Whys

**Prompt:** Our nightly import fails every few days. The only evidence I have is that logs show a timeout when the supplier API is slow. Help investigate and prevent recurrence.

**Expected markers:** separate symptom from confirmed cause; Five Whys as a hypothesis chain, not forced exactly five; label causal hypotheses (assumed, supported, verified, open) and never present an unverified cause as fact; ask for/identify needed evidence; separate immediate relief, cause correction, and system improvement; propose a countermeasure linked to validated cause; define a check.
